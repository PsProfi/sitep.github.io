# Технічна специфікація: Сайт-візитка «Domino's Pizza»

## 1. Загальний опис проекту
Створення статичного сайту-візитки (landing page) для піцерії **«Domino's Pizza»** на базі фреймворку **Bootstrap 3**. Сайт призначений для презентації меню, акцій, відгуків клієнтів, контактної інформації та інтерактивної карти розташування піцерії.

---

## 2. Технологічний стек
- **HTML5** — семантична розмітка сторінки.
- **CSS3** — кастомні стилі для адаптації під фірмовий стиль Domino's (синій, червоний, білий).
- **Bootstrap 3.4.1** — CSS/JS фреймворк для сітки та UI-компонентів.
- **jQuery (1.12.4+)** — необхідний для роботи інтерактивних компонентів Bootstrap 3.
- **Google Maps Embed API (iframe)** — для відображення карти.

---

## 3. Структура та компоненти сторінки

### 3.1. Навігаційне меню (`.navbar`)
- Використання компонента `.navbar` (наприклад, `.navbar-default` або `.navbar-inverse`) з фіксацією або звичайним позиціонуванням.
- **Адаптивність**:
  - На десктопах: горизонтальний список пунктів меню (Головна, Меню, Про нас, Відгуки, Контакти) та логотип компанії (`.navbar-brand`).
  - На мобільних пристроях: меню автоматично згортається в «гамбургер» (`.navbar-toggle`), контент розгортається/згортається через клас `.collapse.navbar-collapse`.

### 3.2. Блок привітання (`.jumbotron`)
- Головний промо-банер (`.jumbotron`) з привабливим фоновим зображенням або фірмовим оформленням.
- Заголовок `<h1>` із привітанням та слоганом піцерії.
- Короткий опис про швидку доставку та свіжі інгредієнти.
- Кнопка заклику до дії (Call-to-Action): наприклад, `.btn.btn-primary.btn-lg` або `.btn.btn-danger.btn-lg` («Замовити піцу» / «Переглянути меню»).

### 3.3. Трьохколонкова сітка послуг / популярних категорій (`.col-sm-4`)
- Блок побудований на базі контейнера `.container` та рядка `.row`.
- **3 колонки з класом `.col-sm-4`**:
  1. **Фірмові піци** (зображення, опис, посилання/кнопка).
  2. **Швидка доставка** (іконка/зображення, переваги доставки за 30 хв).
  3. **Напої та десерти** (зображення, асортимент).
- **Адаптивна поведінка**:
  - На планшетах і ПК (`sm`, `md`, `lg` >= 768px): 3 рівні колонки в один ряд.
  - На мобільних телефонах (`xs` < 768px): колонки автоматично трансформуються в один вертикальний список стовпчиків на всю ширину.

### 3.4. Адаптивний блок відгуків клієнтів
- Секція з реальними відгуками користувачів.
- Використання карток/панелей (`.panel`, `.panel-default` або `.well`) або адаптивної сітки (наприклад, `.col-md-4`, `.col-sm-6`).
- Кожен відгук містить:
  - Ім'я клієнта та аватар / іконку.
  - Рейтинг (зірочки за допомогою гліфіконів `glyphicon-star`).
  - Текст відгуку.

### 3.5. Контактна інформація та вбудована карта
- Секція «Контакти» поділена на 2 частини (наприклад, `.col-sm-6` + `.col-sm-6`):
  1. **Реальні контакти**:
     - Адреса піцерії.
     - Номери телефонів гарячої лінії та доставки.
     - Графік роботи (наприклад, Щодня з 10:00 до 22:00).
     - Електронна пошта.
  2. **Інтерактивна карта Google Maps**:
     - Вбудована через адаптивний контейнер `.embed-responsive.embed-responsive-16by9` з тегом `<iframe>`.
     - Маркер розташування піцерії.

### 3.6. Підвал сайту (`footer`)
- Копірайт, посилання на соцмережі, юридична інформація.

---

## 4. Вимоги до адаптивності та кросбраузерності
- Коректне відображення на мобільних пристроях (`viewport meta tag`).
- Плавні переходи та підтримка роботи меню на iOS/Android пристроях.
- Відповідність фірмовій айдентиці бренду Domino's Pizza.
